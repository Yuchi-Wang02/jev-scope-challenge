    What this preparation tests
    An earlier saved-output audit exposed a target/distractor ID-prefix shortcut. This design gives both requests the same prefix and holds the record block fixed while changing the requested owner. It reuses inspected sentence and policy grammar; it is not a fresh natural-language benchmark.
    Implicit references, aliases, mixed-owner lines and contradictory target facts are outside these examples. The browser highlight is an ordinary explicit-ID equality rule.
