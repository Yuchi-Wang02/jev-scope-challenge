What this result changes
A capable ordinary reference did not reproduce the old signature in its valid labels. It preserved every previously correct control and resolved 47 of 48 repeated old-error decisions; one response was invalid. This narrows the old finding to the tested configurations. It does not tell us which model or inference difference caused the improvement.
Where this stage stops
  • The inputs are authored, already observed and not independently human-reviewed.
  • The twelve vocabulary families share three logical patterns; no population error rate is estimated.
  • This arm is closed. No invalid-answer retry, prompt repair, harder-case expansion or further model sweep follows automatically.
