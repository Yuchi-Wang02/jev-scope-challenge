# Bounded source register and novelty limits

- [CheckList](https://aclanthology.org/2020.acl-main.442/) motivates behavioral
  invariance/directional tests. Paired deletion controls are an application of
  existing evaluation ideas; six-view tests are not a new theory.
- [Calibrate Before Use](https://proceedings.mlr.press/v139/zhao21c.html) estimates
  answer biases using content-free input and calibrates them. Our null request
  is semantically insufficient and is not its few-shot calibration reproduction.
- [Surface Form Competition / DC-PMI](https://aclanthology.org/2021.emnlp-main.564/)
  reweights option likelihood by task-context prior. R1 is a fixed logit-subtraction
  ablation inspired by that general idea, applied to typed scores and a meaningful
  no-evidence control, not the same benchmark or algorithm configuration.
- [Kev historical source](https://github.com/jaredpalmer/kev/blob/29d71c78368657b3a522729a01c748ea15272abc/kev/model.py)
  supplies the unchanged Apache-2.0 pointer/encoder. Native/adapted probes and
  candidate perturbations already exist upstream. No new architecture claim.

Two-order averaging, finite-world enumeration and deterministic known-grammar
parsing are standard components. The present contribution is an inspectable
candidate corpus and diagnostic, not a new learned method or confirmed benchmark.
Human review, broader sources and untouched evaluation remain unresolved.
