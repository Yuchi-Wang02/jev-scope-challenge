# Independent review handoff

Review the 96 supplied items individually using only each item's displayed
records and component policy. This package contains no model outputs, construction
labels, pairing IDs, or another reviewer's judgments. It does not certify blinding.

1. Extract this package to a local folder and open `review.html` in Chrome or Edge.
2. Use your own reviewer ID (for example `reviewer_B`), browser profile and files.
3. Read the request, policy and records. Enter the target order, destination,
   label, evidence paths, ambiguity flag, and a reason for every item.
4. If an identity cannot be resolved, enter `UNRESOLVED`. Use the displayed
   evidence to distinguish an established valid destination, an established
   invalid destination, and `NOT_ESTABLISHED`. Explain uncertainty in your notes.
5. Click **Save item** before changing the Item dropdown. Switching items does
   not save edits automatically. Export the CSV regularly and before closing.
6. Return your CSV and a completed `cover_note.txt`. Keep your original export.

The task judges only the refund-destination restriction, not authorization for a
complete return or refund operation. Evidence paths can cite multiple records,
but the notes must explain why they apply. Do not fill missing evidence using
another item, external databases, model predictions, or another person's answer.
Chinese or English explanations are acceptable.

Use your own judgment. Do not use AI to supply or revise item judgments; record
any assistance or exposure honestly if it occurred. Do not consult project
results or discuss judgments with another reviewer before both initial exports
are preserved. The public project is accessible, so record any prior exposure.
There are repeated forms of underlying scenarios; they are not independent cases.

`inputs.jsonl` is the same input data shown by the page. `reviewer_B.csv` is an
optional blank template if you prefer a spreadsheet. The page automatically
records save timestamps; spreadsheet users should record actual review dates.
Browser storage is only a convenience. The exported CSV is your portable copy.
Do not overwrite the blank template or reuse another reviewer's ID.
