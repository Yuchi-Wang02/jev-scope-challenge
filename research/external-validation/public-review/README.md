# Downloadable ShARC review package

[Download the ZIP](review_package.zip), extract it, and open `review.html` in a
browser. Give each reviewer a separate copy and browser profile. The page starts
blank and makes no network requests. Enter a stable reviewer ID, select
**Start / resume**, judge each visible item, and download your CSV. Return that
CSV and the completed `cover_note.txt` to the project owner. Nothing is uploaded
automatically. Save your initial answers before discussing them with anyone.

The ZIP includes neutral instructions, a blank CSV and attribution. It contains
60 items and **zero completed human reviews**. Do not read other project reports,
source answers or another review before completing your initial review. Public
source availability means procedural blinding cannot be guaranteed.
