# 下一期实验设计草案：同底座的决策能力变化

状态：研究计划，未执行。2026-09-29。先导与确认性研究分开；此文件不是预注册完成的声明。

**标题候选：Is the Decision Model Better Than the Model It Came From?**

本期问题：在同一个精确版本的底座上，公开决策训练的参数改动与专用读出，分别如何影响关系绑定和证据不足的决策？

## 为什么先做它

旧实验发现冻结 Qwen3-4B 某种读出在对象绑定上的失败，但 Jev 的底座/训练不可知，因而无法把差异归因于专用训练。Kev 提供开放 adapter、head、训练记录及原始 LM-head 对照。先用这些已有材料做低成本定位，再决定是否需要训练新方法。

上游已经有 native/adapted LM-head、角色 decoy、证据删除与多种修复。我们对此明确引用。新一轮作为独立复现/任务扩展；只有新机制和新数据上的泛化证据足够，才进一步主张论文贡献。

## 第一阶段的比较臂

| ID | 模型权重与输出 | 能回答的问题 |
|---|---|---|
| N0 | 精确 Base，原始 LM head，固定字母/序列评分 | 未做这次决策适配的基础表现 |
| N1 | 同一 Base + 指定 Kev LoRA，原始 LM head；与 N0 相同 prompt/评分/精度 | 该参数改动对原输出路径的影响 |
| K1 | 同一 adapter 与它共同训练的 pointer head，Kev 原生格式 | 完整开放决策系统表现 |
| C0 | 可执行语法/结构化解析参照 | 哪些输入的语义工作实际上可由规则完成 |

N0 对 N1 的对照更干净，但仍只对应一个 adapter、训练历史和任务总体。N1 对 K1 改变了格式、mask、选项表示和读出，不能纯归因于 head。Jev 与 Laya 若加入，作为外部系统参照分别计预算；不是同底座因果对照。

在 N0/N1 的 native readout 中，约束为相同前缀的 greedy 单字母生成与候选字母 argmax 通常是同一决策，不能把它们当两种独立推理方法。额外生成/思考方案必须明示新增 token 与计算。

## 数据与金标准

旧 12 个母例已曝光结果，作为开发/回归样本。新先导建议 24 个母例覆盖三个任务家族，例如订阅/权限动作、业务记录关系、对话中当前有效请求。该数量用于探测信号，不作为正式研究的充分样本量。

每个母例至少具有以下视图，分组划分不能拆散：

1. **充分证据原例**：目标对象、动作、有效来源清楚。
2. **等义表示变化**：换顺序、格式或无关实体名，决定应保持。
3. **关键关系变化**：改动作对象/来源角色/有效指令，决定按规则改变。
4. **决定性证据缺失**：删除唯一支持决定的事实，标签为 INSUFFICIENT，而非沿用原 yes/no。

不能机械地认为删一句就必须未知：逐例检查剩余内容和领域规则是否仍能推断。对矛盾证据另定义处理规则。可执行 DSL/表格规则负责精确运算和结构真值；自然语言改写由独立审核者核实关系是否保留。凡有歧义，保留记录、版本化修正；不得根据某模型失败与否删题。

为检验语法外泛化，留出整类表述/来源/关系组合，不仅换实体名字。若加入真实文档，先核实使用条件与证据可判定性；避免让模型通过常识猜出处缺失的信息。所有后端得到同样事实与计算结果，不能把 oracle 解析后的字段只给新方法。日期、金额、排名等派生事实必须只从每个变体剩余的证据重新计算；证据删除后不能保留由已删除事实算出的答案。此设置测量共同确定性预处理后的关系决策，不能宣称测到了原始算术能力。

开发、校准、最终测试按母例/模板/文档分组，并记录审核者。若只有 AI 标签检查，就写明并把结论保留为探索性。确认性研究的独立 holdout、样本量、最小有意义效应与模型选择规则在先导后另行制定，不能用已看过的测试反复调方法。

## 必须先修正的测量问题

- Kev 原始 probe 的 plain 模板对 null 描述会打印 None；应与 API 一致回退 option key，加入检查。
- 它只定义 16 个答案字母并未验证单 token；在本实验中明确选项数和实际 token 边界，不静默取多 token 编码的第一项。
- native 与 pointer 默认 GPU 精度不同；统一或把 dtype 作为显式独立因素。记录实际核函数、device、量化、warmup。
- 所有 arm 记录真正到达模型的 token IDs/长度/截断与选项是否坍缩。模型没看到证据的失败，不归因为语义绑定能力。
- raw 与 temperature-scaled 概率分别报。使用相同校准数据与拟合流程，但每个 arm 独立拟合温度，不强迫共用一个数值。对各候选施加同一正温度的缩放不改 argmax，也不提供 OOD 校准保证。
- 原始输入、序列化 prompt、权重、adapter、head、tokenizer、code 和环境都固定。每次运行独立输出目录和 session manifest；全缓存运行不能覆盖旧环境。
- 保留失败、拒绝、超限、重试与未完结请求；不在分母里隐去。

## 主要观察与判定

主要看按母例分组的完整正确率、关键关系翻转的正确性、等义变化保持正确的比例、证据不足时误接受率。另报各类标签正确率、概率质量、预先校准阈值下的测试 risk/coverage、推理用量和延迟。

只有支持/反对/不足的事件定义明确时才比较三分类概率。不要把 Jev API confidence、最大概率、归一化 entropy 或 action-head 值直接混为一种分数。温度或阈值不能在最终测试上挑最优。按原始母例/文档重采样，多 seed 属于训练变异，不能把每个变体当独立样本。

| 先导观察 | 可支持的下一步 | 不支持的结论 |
|---|---|---|
| N1 在同 prompt 下比 N0 稳定更差 | 研究这次 adapter 带来的能力取舍 | 所有决策训练都会遗忘 |
| N1 接近 N0，但 K1 在新输入上差 | 检查 pointer 路径/布局/训练目标，随后训练适当 head-only 控制 | 单凭三臂已证明 head 是唯一原因 |
| K1 稳定更好 | 检验哪些条件的收益需要 body adaptation | Jev 的秘密架构已经被解释 |
| 格式/截断控制后差距消失 | 报告测量修正与表示敏感性 | 继续沿用原来的模型能力结论 |
| 所有简单规则都足够 | 给出规则覆盖范围与未覆盖任务 | 人工小语法证明所有自然语言不用模型 |
| 只在旧模板/同教师标签上有效 | 归为局部适配或教师一致性结果 | 通用可靠决策方法 |

## 第二阶段：最小 research fork

只在第一阶段有可重复信号时加入训练：

- H0：从不含现有 Kev adapter 的指定 Base 起步，底座完全冻结，仅训练新 pointer head。
- H1：从与 H0 相同的原始 Base、相同新 head 初始化起步，head + 新初始化的 LoRA 联合训练；不沿用 K1 已训练的 adapter。
- 至少多个训练 seed；既比较匹配样本/步数，也单独报告训练计算成本。两组获得相当的合理调参预算并在独立开发集选模，不强制同一学习率；优化不足的 head-only 不能作为必须更新底座的证据。
- 明确 backbone/adapter 的 requires_grad、optimizer 参数、训练前后权重 delta，以及 resume 的冻结状态。
- “把 H1 的联合训练 head 插回未适配底座”可以作为 co-adaptation 消融，但不是 H0 的替代。

head_only 功能、严格 manifest 和 native readout guards 是适合向 Kev 贡献的小补丁。先本地复现与测试，保留上游许可及来源。新方法若只是普通 head learning 或既有 counterfactual augmentation，就按工程/复现贡献表述。

若探索新的关系敏感训练：数据、普通 CE、相同反事实样本 CE、一致性约束、已有 none-pair/anchor loss 都要比较。不能把更多标签或更多计算伪装为新损失有效；不能对改变正确答案的变体强制答案一致。

## 输出、成本与停止条件

第一阶段产物：experiment manifest、按母例数据卡/审核表、native 与 Kev 适配器、raw records、离线完整核验、全体结果图、2–4 页研究笔记及限制。已有模型的新诊断无需先创建 HF 模型页。数据审核后可发布 HF dataset；只有新增训练并有足够证据时再发布 adapter/head。

本轮尚未为该新实验确定付费预算。规划以已有本地 GPU 为起点；权重下载、依赖兼容、运行时间与峰值内存先盘点，不能用上游 H100/Mac 数字推算本机收益。若加入 Jev、教师标注或云训练，先给出调用数/数据量/完整费用上限。原实验的 USD 1 停止阈值不能自动沿用为任意新实验授权。

阶段停止：没有未见样本上的信号就不扩大训练；普通基线解释全部收益就不声称新算法；标签不能独立判定就修数据；没有严格 matched 配置就只能报告系统比较。接受负结果，不为某个标题继续改题。
