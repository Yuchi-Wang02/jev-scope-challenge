# Original pilot data

24 synthetic parents, four views each, three task families. Constructed from
structured facts with a deterministic label oracle. Natural-language renderings
are AI-written and AI-checked, not independently human reviewed. Use as an
exploratory diagnostic, not as a validated production benchmark.

Split whole parents/styles: 6 development, 6 calibration, 12 exploratory test.
Each candidate order is a repeated measurement, not a new independent sample.
The oracle reads structured construction facts; models only see rendered text.
